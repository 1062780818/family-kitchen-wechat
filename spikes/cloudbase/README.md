# CloudBase隔离架构小样

本目录只验证FK-C01-003要求的四项最小能力，不是正式后端、数据库设计或业务交付，不连接真实CloudBase，不包含AppID、密钥、真实账号或照片。

证据等级：

- `src/core.mjs`与`test/core.test.mjs`：本地模拟通过。
- `src/cloudbase-adapter.example.mjs`：按官方服务端SDK接口编写的适配示例，仅文档／静态分析，未在云端调用。
- `rules/*.json`：建议的默认拒绝客户端直连基线，仅静态配置草案，未部署。
- 微信身份、真实数据库事务、云存储权限规则及云函数调用：未验证，需要有效CloudBase环境与小程序权限。

## 验证约束

1. 微信身份只能由服务端适配器提供，业务请求体中的`openid`、角色及家庭ID都不能成为授权事实。
2. 所有数据和文件操作先查询服务端家庭成员关系；跨家庭访问拒绝。
3. 小样将数据库和存储客户端规则设为默认拒绝，读写都经可信云函数；这是因为服务端SDK可绕过客户端安全规则，函数内部仍必须再次授权。
4. 写操作使用`familyId + actorId + requestId`派生幂等键，同一键同一载荷返回原结果，不同载荷冲突。正式实现必须用CloudBase服务端事务／确定性文档ID或数据库唯一约束，不可依赖单进程Map。

运行：

```powershell
node --test spikes/cloudbase/test/core.test.mjs
```

本小样故意不实现菜品、餐单、亲亲或页面；未确认的业务规则不能借小样冻结。
