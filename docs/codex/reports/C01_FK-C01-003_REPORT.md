## 4. CloudBase最小小样

位置：`spikes/cloudbase/`。小样没有引入SDK或连接云端，只把平台依赖放在适配边界：

1. `trustedWechatIdentity`只接受服务端上下文，拒绝匿名及请求体伪造身份；示例适配器调用服务端`auth.getUserInfo()`，不读取`event.openid`。
2. 所有数据／文件操作先检查`familyId + actorId + active`成员关系；跨家庭拒绝。
3. 虚构测试图片只允许同家庭读，删除默认仅所有者；客户端数据库和存储规则草案均为`read:false/write:false`，业务通过可信函数授权。所有者之外谁可删尚未冻结，小样不替产品决定。
4. 最小写入用`familyId + actorId + requestId`派生确定性键并校验载荷哈希；同键同载荷重放原结果，同键不同载荷冲突。

执行`node --test spikes/cloudbase/test/core.test.mjs`：8通过、0失败、退出码0。证据为`spikes/cloudbase/TEST_RESULTS.md`。

证据等级：

| 能力             | 等级                                   | 结果                                                             |

| 可信微信身份     | 官方资料＋静态适配分析；真实云端未验证 | 官方服务端SDK能从运行上下文取得openId／uid；本地拒绝伪造输入通过 |

CloudBase官方文档说明数据库安全规则可做文档级控制；云存储规则可用`auth.openid`／资源所有者控制读写，但服务端SDK始终有全部文件权限，因此云函数内部家庭授权不能省略。数据库事务仅服务端Node SDK支持，并有单事务最多100操作、30秒和只支持`doc`等限制。本小样需的写入规模在能力边界内，但真实冲突语义必须实测。

## 6. 推荐路线
