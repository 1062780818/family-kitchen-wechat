## 3. FK-C03-004-01｜迁移备份 S1

```powershell
pnpm --filter @family-kitchen/backend run storage:refs:preview --env-file="<absolute-env>"
pnpm --filter @family-kitchen/backend run storage:refs:apply --env-file="<absolute-env>" --backup="<absolute-new-backup>"

```

真实数据库和 MinIO 结果：

1. preview 识别 1 条可信签名 URL 且不改库；apply 转为稳定 `family/...` key，并在命令指定的仓库外绝对路径生成 `version=1`、`changes=1` 的 JSON。
2. apply 后 preview 为 0；第二次 apply 使用另一新备份并应用 0 条；该 0 变更备份 rollback 恢复 0 条；原备份 rollback 恢复 1 条旧值。
3. 字面量 `--`、相对路径、缺失备份参数、未知参数、父目录不存在、已有备份六类调用均退出 1；每次前后数据库旧值计数均为 1，未发生修改。
4. apply 后人工模拟记录再次编辑，rollback 退出 1，编辑后的当前值保持不变。
5. 六个测试备份均位于精确的仓库外目录，文件实际存在、版本正确；0 变更和 1 变更备份可区分；仓库内没有同名备份，`backend/--` 不存在，没有静默覆盖或人工移动步骤。
6. 插入一个无法核实来源的外部签名 URL 记录后，preview 成功但该记录前后均原样存在，未被分配、转换或删除。
