# 第一版认证与管理入口技术范围 V0.1

日期：2026-09-07  
依据：FK-C01-007；架构路线为“现有小程序前端＋保留并精简原独立后端”。

## 已确定边界

1. 第一版正式用户入口只采用微信身份与家庭邀请，不保留原项目面向用户的手机号密码注册、登录入口。
2. 生产环境服务端的 `/auth/password-login` 固定拒绝；`PASSWORD_LOGIN_ENABLED=true` 在生产配置校验阶段即拒绝启动。
3. 非生产隔离环境可显式设置 `PASSWORD_LOGIN_ENABLED=true`，仅用于自动化测试。该开关不是正式运行兜底，也不代表微信登录或真机验证通过。
4. 原管理入口为可选模块且默认关闭。只有 `ADMIN_ENABLED=true`、用户名非空、密码不少于12字符且不是原固定默认凭据时，才允许启动管理访问链路。
5. 管理入口关闭或配置无效时，管理员登录与所有受管接口均拒绝。已经签发但用户名与当前配置不一致的管理员令牌也拒绝。
6. 本轮没有新增完整微信登录、扫码、找回密码或管理后台功能；真实微信登录、通知和真机仍是后续验收条件。

## 给C02的接口影响

- 小程序/H5共享认证API、认证状态仓库和登录页已移除密码登录调用；非微信构建仅提示第一版需要微信小程序。
- 不得重新暴露手机号、密码输入及“未注册自动创建”文案。

## 给C03的验收边界

- 生产模式应拒绝密码入口，且无法通过配置误启用。
- 管理配置缺失、空、部分配置、原固定默认值、管理入口关闭、伪造或旧管理员身份均不得取得管理权限。
- 隔离测试身份允许仅限非生产且必须显式开启；该结果不得记作真实微信登录通过。
