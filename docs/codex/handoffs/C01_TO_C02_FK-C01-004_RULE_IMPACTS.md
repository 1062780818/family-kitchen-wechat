# C01交接C02｜FK-C01-004 前端规则影响

来源分支：`codex/01-business-rules-freeze`。本文件只准备下一轮交接，未通知或启动C02；须由外部任务调度启动C02读取。

## 必须移除的旧草案／交互

1. 不显示小／正常／大份，不保留分量Store字段、选择器、加价或替代规格。
2. 不显示“送上亲亲”、已送／未送、待支付／已支付、亲亲余额／欠账／累计收取；上菜后主流程结束。菜价、餐单快照和合计仍展示。
3. 菜单外菜改为独立愿望清单入口和列表，只采集菜名、图片、参考链接；不得加入购物车／当前餐单、弹出本餐报价或计入合计。
4. 评价改为每个餐单菜品三档可选，整单一句话可选；不得沿用星级、自动评价、奖励或强制评价弹窗。

## 必须新增／修订的界面状态

1. 日期控件仅今天至＋7天并包含两端；餐次为早餐／午餐／晚餐，预计开饭时间单独保留。
2. 同家庭／日期／餐次已有待确认、已接单或做饭中餐单时，提交结果引导进入已有餐单；不能显示第二张创建成功。
3. 命中已有已接单／做饭中餐单不等于可修改，编辑和取消按钮等待剩余业务规则冻结。
4. 调整提交／确认仍保留请求中、重复点击保护、版本冲突和失败恢复；不得因取消亲亲送达幂等测试而删除通用保护。

受影响候选：`order/create`、`order/detail`、菜单／餐单Store和API、旧rating／love-point页面及消息标签。正式字段和接口待C01后续契约任务冻结，C02不得在本轮自行实现。
